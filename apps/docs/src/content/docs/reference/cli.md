YAPZM is used from the terminal with the `yapzm` command. Running it without arguments prints help.

## Commands

### `yapzm health`

Checks your machine and reports what it finds:

- Detected game clients (Steam)
- Detected Project Zomboid installs, with status and version
- Detected Workshop content

Use `--verbose` (or `-v`) for more details, such as library paths, install locations, and the game revision.
